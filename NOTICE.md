# Notice

This repository currently contains project description files, documentation
drafts, and lightweight figures for the LEVIRDet project.

The full image tiles, annotations, source-license manifest, code, and trained
models will be released in a versioned project repository at
<https://qinzheyang.github.io/LEVIRDet-Website/>, accompanying the final paper.

Figures included in this repository are provided for project presentation and
documentation. Dataset and model artifacts are not included in this pre-release
repository.
