# Release Plan

This repository is a pre-release project repository. The current content is
intended to provide the public project description, figures, demo links, and
planned release structure.

## Planned Milestones

- **Project page and web demo:** available through the GitHub Pages project site.
- **Paper metadata:** to be updated after the final paper is available.
- **Dataset release:** image tiles, annotations, taxonomy, splits, and
  source-license manifest.
- **Model release:** code, configs, inference scripts, evaluation scripts, and
  trained checkpoints.
- **Versioned release:** all artifacts will be versioned and checksummed.

## Current Download Notice

The full image tiles, annotations, source-license manifest, code, and trained
models will be released in a versioned project repository at
<https://qinzheyang.github.io/LEVIRDet-Website/>, accompanying the final paper.
