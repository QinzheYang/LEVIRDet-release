# LEVIRDet-159 Dataset

LEVIRDet-159 is a million-scale remote sensing object detection dataset designed
for broad-category, fine-grained, and cross-domain detection research.

## Summary

- **159 categories** under a multi-level taxonomy.
- **~2.56 million bounding boxes**.
- **~700k fine-grained annotations**.
- Broad spatial-resolution, sensor, scene, and geographic coverage.
- Tight horizontal bounding-box protocol for universal remote sensing object
  detection.

## Taxonomy

LEVIRDet-159 covers 30 parent categories and expands aircraft, vehicle, and ship
categories into fine-grained multi-level labels. The final release will include
the full taxonomy table, parent-child relationships, and category metadata.

## Planned Release Contents

The dataset release is planned to include:

- Image tiles.
- COCO-style annotations.
- Fine-grained hierarchy annotations.
- Source-license manifest.
- Dataset split files.
- Evaluation protocol definitions.
- Dataset statistics and category descriptions.

The full image tiles, annotations, source-license manifest, code, and trained
models will be released in a versioned project repository at
<https://qinzheyang.github.io/LEVIRDet-Website/>, accompanying the final paper.
