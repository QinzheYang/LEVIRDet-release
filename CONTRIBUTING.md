# Contributing

Thank you for your interest in LEVIRDet.

This repository is currently in a pre-release stage. We are not yet accepting
external code contributions because the training code, dataset, and model
checkpoints have not been released.

After the versioned release, we plan to accept:

- Issue reports for dataset metadata or documentation.
- Reproducibility questions.
- Pull requests for documentation improvements.
- Pull requests for examples and evaluation utilities.

Please do not upload private datasets, credentials, or unreleased third-party
data into issues or pull requests.
